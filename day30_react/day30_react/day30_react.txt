* Controlled and uncontrolled components

Controlled component:
- React controls the form data
- The value is stored in React state, not inside the DOM
- we always use value={state} and onChange.

When it is best to use?
    - Validations
    - Dynamic error messages
    - Consition UI update
    - Form that needs to be submitted to API

uncontrolled component:
- The DOM itself control the form data
- we use ref to access the value
- No React state for storing input
- No rendering, which improves the component performance

Best to use?
- Very simple form
- When you just want input values on Submit event/click

formik library will help to avoid re-rendering of component when we have complex forms
