What are synthetic events?
 In React, synthetic events are React's own wrapper around the browser's native events.
    e.i = ReactSyntheticEvents(BrowserNativeEvents)

    <button onClick={handleClick}>Click</button>
        The onClick is a synthetic event, not the browser's native event 
    React wraps the browser event inside its SyntheticEvent object.

Why react uses synthetic events?
    1. Cross browser compatiblity
        Different browser behave differently with native events.
        React makes everything consistent.
    
    2. Event delegation
        Instead of attaching events to every elements, it attches them at root and maps events efficiently.
    
    3. Works with React's Virtual DOM
