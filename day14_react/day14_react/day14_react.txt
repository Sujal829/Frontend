HTTP API Methods:
    - Communication between Web and server
    - HTTP: is a protocol use to send and receive data.

How does HTTP works?
    - Client (browser) send a request to the server
    - Server (Backend App) processes the request
    - Server sends a request back to client.

Baseurl: https://jsonplaceholder.typicode.com
endpoint: /posts, /users, /user/{1}

Types:
    GET: Read data from server 
    POST: Create new data or perform an operation
    PUT: Updating existing data
    PATCH: Partially update data
    DELETE: delete the record

HTTP status codes:
 erros are further classified as following:
    2xx Success
        200  OK 
        201  Created
        202  Accepted
        204  but no body


    3xx Redirection
        301: Moved permanently 
        302: Found
        304: Not modified

    4xx Client Error
        400: Bad request Invalid syntax or params
        401: Unauthorized Invalid Authentication (session expired)
        403: Forbidden (Access denied)
        404: Not Found
        429: Too many request 

    5xx Server Error
        500: Internal server error
        501: Not implemented - Method not supported by server
        502: Bad Gateway - 
        503: Service unavailable - Server down or overloaded
        504: Gateway timeout - 
        505: HTTP version not supported
