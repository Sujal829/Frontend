2. How does the react manage the Virtual DOM, and what are the benefits?
    - creates the copy of real DOM in memory and compares changes
    - reconcilation process
    - React updates only changed nodes -> faster in performance
    - setCount(count+1) - invoke the change or life cycle

3. Can react hooks fully replace Redux for state management?
    - Not fully
    - Hooks manages the local state
    - For complex gloabl state we need Redux
